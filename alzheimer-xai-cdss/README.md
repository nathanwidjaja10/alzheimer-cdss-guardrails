# Alzheimer XAI CDSS (frontend)

React and Vite clinician portal for the clinical decision-support system. It lists the subjects and sessions of
both cohorts, shows the MRI in 2D and 3D (NiiVue), requests a prediction with explanations from the backend
(`http://localhost:8000`), and displays the FHIR R4 bundle, the guardrailed LLM narrative and the follow-up
Q&A panel.

## Run

```bash
npm install
npx vite          # http://localhost:5173
```

The backend must be running (see the repository README). Use `npx vite` rather than `npm run dev`: the
`predev` hook runs `generate_manifest.js`, which regenerates `src/data.json` from the local imaging data and
overwrites the committed catalogue when that data is absent.

## Contents

| File | Purpose |
|---|---|
| `src/App.jsx` | Main application: subject list, viewers, CDSS modal (diagnosis and XAI, clinical summary, FHIR JSON, rules and validation, conformance), narrative and Q&A panels |
| `src/NiiVueViewer.jsx` | Volume viewer with an optional segmentation overlay |
| `src/RoiDemoViewer.jsx`, `src/roiDemoData.js` | Anatomical ROI reference pop-up: two synthetic BrainWeb demo volumes (reference volumes in the captions come from OASIS-3 samples) and the label colour table |
| `src/data.json` | Subject and session catalogue generated by `generate_manifest.js` |
| `generate_manifest.js` | Builds `src/data.json` from `dummy_data/` (and from `oasis_data/` and `adni_data/` when present) |
| `generate_roi_demo.py` | Builds the demo volumes in `public/demo/` from `dummy_data/` |
| `vite.config.js` | Vite configuration; rewrites the absolute data URLs of the manifest to the local checkout |
